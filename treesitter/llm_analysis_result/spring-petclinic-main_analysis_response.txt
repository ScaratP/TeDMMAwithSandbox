- **Dependency Graph**:
    - OwnerService -> PetService:
        - Type: REST
        - Logic: OwnerController.findPet
        - Path: /owners/{ownerId}/pets/{petId}
    - OwnerService -> VisitService:
        - Type: REST
        - Logic: VisitController.processNewVisitForm
        - Path: /owners/{ownerId}/pets/{petId}/visits/new
    - PetService -> PetTypeService:
        - Type: REST
        - Logic: PetController.populatePetTypes
        - Path: /pets/new
    - VetService -> OwnerService:
        - Type: REST
        - Logic: VetController.showVetList
        - Path: /vets.html

- **Data Schemas**:
    - OwnerService API DTOs:
        - Owner: [id, name, firstName, lastName, address, city, telephone]
    - PetService API DTOs:
        - Pet: [id, name, birthDate, typeId]
    - VisitService API DTOs:
        - Visit: [id, date, description]
    - VetService API DTOs:
        - Vet: [id, firstName, lastName, specialties]
